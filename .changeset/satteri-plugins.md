Add Sätteri plugins for Astro 7's default Markdown processor. `rehype-code-group/satteri` exports `satteriCodeGroup`, which takes the same options and writes the same HTML as the rehype plugin, and `satteriCodeGroupLabels`, the counterpart of the remark companion for `[label]` fence metadata. Supports `satteri` 0.10.5 to 0.11.x as an optional peer dependency.
